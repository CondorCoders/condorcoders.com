# CondorCoders Web

Repositorio oficial de la página web de CondorCoders.

CondorCoders es una comunidad enfocada en programación, tecnología y colaboración entre developers de LATAM y la comunidad hispana alrededor del mundo.

La página web funciona como el espacio principal para compartir proyectos, eventos, contenido y recursos de la comunidad.

---

# Sobre la comunidad

CondorCoders busca crear un espacio donde developers puedan:

- aprender programación en español
- colaborar en proyectos
- compartir conocimiento
- participar en eventos y streams
- crear experiencias web y herramientas para la comunidad

---

# Cómo contribuir

Existen diferentes formas de aportar al proyecto y a la comunidad.

## Reportar bugs

Si encontraste un problema en la página web, puedes crear un issue.

Antes de hacerlo:

1. Verifica si el problema ya fue reportado
2. Intenta reproducir el bug
3. Incluye información clara y detallada

Ejemplo:

- pasos para reproducir el problema
- navegador utilizado
- sistema operativo
- capturas de pantalla
- comportamiento esperado

### Crear un issue

```txt
Título:
El menú mobile no se puede cerrar en Safari

Descripción:
Al abrir el menú mobile en Safari iOS 18, el botón de cerrar no responde.

Pasos para reproducir:
1. Abrir la página en iPhone
2. Abrir el menú mobile
3. Presionar el botón cerrar

Resultado esperado:
El menú debería cerrarse correctamente.
```

Issues del proyecto:

https://github.com/TU-USUARIO/condorcoders-web/issues

## Contribuir código

### 1. Hacer fork del repositorio

Haz fork del repositorio desde GitHub.

Luego clona tu fork:

```bash
git clone https://github.com/TU-USUARIO/condorcoders-web.git
```

---

### 2. Entrar al proyecto

```bash
cd condorcoders-web
```

---

### 3. Instalar dependencias

```bash
npm install
```

o

```bash
pnpm install
```

---

### 4. Ejecutar el proyecto

```bash
npm run dev
```

---

# Crear una rama

Usa nombres descriptivos para tus ramas.

Ejemplos:

```bash
git checkout -b fix/navbar-mobile
```

```bash
git checkout -b feature/community-section
```

```bash
git checkout -b refactor/footer-links
```

---

# Commits

Intenta usar mensajes claros y descriptivos.

Ejemplos:

```bash
git commit -m "fix: corrige problema del navbar mobile"
```

```bash
git commit -m "feat: agrega sección de eventos"
```

```bash
git commit -m "docs: actualiza instrucciones del README"
```

Prefijos recomendados:

- feat
- fix
- docs
- refactor
- style
- chore

---

# Merge Requests / Pull Requests

Cuando abras un Merge Request o Pull Request incluye información clara sobre los cambios realizados.

## Ejemplo de título

```txt
feat: agrega sección de proyectos de la comunidad
```

---

## Ejemplo de descripción

```md
## Cambios realizados

- se agregó una nueva sección de proyectos
- se mejoró el responsive mobile
- se actualizaron estilos del footer

## Capturas

Agregar screenshots o videos aquí.

## Verificaciones

- [x] probado localmente
- [x] responsive
- [x] sin errores en consola
```
